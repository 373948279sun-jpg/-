# 小游戏

两个单文件的浏览器小游戏，打开就能玩，不需要安装或构建。字体来自 Google Fonts，离线时会换成系统字体。

## 木人擂台

3D 格斗。打开 [`muren/index.html`](muren/index.html) 就能玩。3D 画面用 three.js r128，从 cdnjs 加载，所以要联网。

华山绝顶一座擂台，四尊漆木人各守一方，名字和颜色取自四象：青龙出招最远，白虎力气最大，朱雀最快，玄武最扛打。选一尊上台和电脑比武，三局两胜：把对手打倒，或者把它打下擂台。

- 键盘：A、D 前后，W、S 侧闪，J 拳，K 腿，按住 L 格挡，气满后按 I 放绝招，P 暂停
- 手机：左手摇杆走位，右手拳、腿、挡、绝，横屏更好玩
- 拳打中后接着按“拳、腿”能打出三连击
- 侧闪能躲开正面来的拳脚；绝招挡不住，只能闪
- 擂台边上的暗红带是险区，在那里挨一套连招就会被打出界
- 电脑对手分新手、熟手、高手三档
- 每尊木人的胜负战绩存在本机浏览器里

## 华容道

三国题材的滑块棋。打开 [`huarongdao/index.html`](huarongdao/index.html) 就能玩：挪开挡路的兵将，把曹操送到棋盘底部的出口。

- 按住棋子拖动；只有一条路可走的棋子，轻点就会移动
- 键盘：Tab 选棋子，方向键移动，Ctrl+Z 撤销
- 计步按老规矩：同一枚棋子连续挪动，不论走几格，只算一步
- “提示”标出下一步的最优走法，“看解法”自动演示最少步数的走法
- “重来”之后还能用“撤销”找回刚才的棋局
- 每个布局的最佳成绩存在本机浏览器里；用过提示或看过解法的对局不计成绩

| 布局 | 最少步数 |
| --- | --- |
| 残局一（入门） | 12 |
| 残局二（入门） | 20 |
| 左右布兵 | 54 |
| 一路进军 | 58 |
| 齐头并进 | 60 |
| 指挥若定 | 70 |
| 兵分三路 | 72 |
| 横刀立马 | 81 |

两个入门残局取自横刀立马最优解的后半程。表里的最少步数都用页面内置的求解器（广度优先搜索）核对过。
