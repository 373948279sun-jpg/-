# 华容道

三国题材的滑块棋。赤壁一败，曹操退往华容道：挪开挡路的兵将，把曹操送到棋盘底部的出口。

## 怎么玩

用浏览器打开 [`huarongdao/index.html`](huarongdao/index.html) 就能玩。整个游戏只有这一个文件，不需要安装或构建。字体来自 Google Fonts，离线时会换成系统字体。

- 按住棋子拖动；只有一条路可走的棋子，轻点就会移动
- 键盘：Tab 选棋子，方向键移动，Ctrl+Z 撤销
- 计步按老规矩：同一枚棋子连续挪动，不论走几格，只算一步

## 收录的布局

| 布局 | 最少步数 |
| --- | --- |
| 残局一（入门） | 12 |
| 残局二（入门） | 20 |
| 左右布兵 | 54 |
| 一路进军 | 58 |
| 齐头并进 | 60 |
| 指挥若定 | 70 |
| 兵分三路 | 72 |
| 横刀立马 | 81 |

两个入门残局取自横刀立马最优解的后半程。表里的最少步数都用页面内置的求解器（广度优先搜索）核对过。

## 其他

- “提示”标出下一步的最优走法，“看解法”自动演示最少步数的走法
- “重来”之后还能用“撤销”找回刚才的棋局
- 每个布局的最佳成绩存在本机浏览器里；用过提示或看过解法的对局不计成绩
- 跟随系统的浅色和深色模式
